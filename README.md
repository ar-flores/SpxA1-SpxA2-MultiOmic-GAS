## Overview

This repository contains all analysis code supporting a multi-omic investigation of the SpxA1 and SpxA2 transcriptional regulator paralogs in *Streptococcus pyogenes* MGAS10870 (emm3). SpxA1 and SpxA2 interact with RNA polymerase to modulate virulence gene expression; SpxA2 is directly regulated by the LiaFSR three-component system in response to antimicrobial peptide stress. Using RNA-seq, NanoString nCounter, DIA proteomics, and CovR ChIP-exo, we define the distinct and overlapping regulons of these two paralogs and establish a stoichiometry-dependent model of virulence gene control.

**Key findings:**
- SpxA1 and SpxA2 have largely non-overlapping transcriptomes under AMP stress
- SpxA2 loss bidirectionally modulates CovR DNA occupancy in a promoter-class-dependent manner (439 differential sites, FDR < 0.05)
- ChIP-exo motif analysis confirms class-specific dimer vs monomer CovR binding
- Multi-omic integration supports a rheostat model of SpxA1/SpxA2 co-regulation

## Analysis Modules

### 1. NanoString nCounter (`NanoString_RNAseq/`)

**`01_NanoString_analysis.R`** — Full NanoString pipeline:
- Import nSolver v4.0 normalized counts (119 probes: 116 endogenous + 3 HK)
- PCA QC; exclusion of spxA1KO hNP-1 rep1 (PCA outlier)
- limma empirical Bayes DE: 12 contrasts (6 within-strain, 6 cross-strain)
- Hierarchical clustering → k=4 gene modules (86 probes)
- Heatmap, module profile plots, supplemental tables

**`02_RNAseq_DESeq2_validation.R`** — RNA-seq and cross-platform validation:
- DESeq2: spxA1KO vs WT and spxA2KO vs WT (UI condition, 9 samples)
- Cross-platform concordance: NanoString logFC vs DESeq2 logFC (97 probes)
- Expression correlation: WT NanoString vs RNA-seq log₂(TPM+1)
- Requires: `NanoString_workspace_noMo.RData` from Module 1

**`02_NS_genbank_crosswalk.py`** — Probe-to-genome mapping:
- Maps NanoString probe IDs (MGAS5005 M5005_Spy_) to MGAS10870 C9Q_ locus tags
- Four-tier strategy: SpyM3 direct lookup → exact protein → gene name → k-mer (k=10, Jaccard ≥ 0.5)
- Run once; output (`NS_crosswalk_final.csv`) used by Module 2

### 2. ChIP-exo (`ChIPexo/`)

**`chipexo_pipeline.sh`** — Bash pipeline:
- Reference genome preparation (GenBank → BED + FASTA)
- BAM renaming, merging (SAMtools), indexing
- Peak calling: MACS3 (score >5000 visualization; >3000 DiffBind)
- ScriptManager v0.14 composite tag pileup
- MEME de novo motif discovery + FIMO known motif scanning
- Horstmann 2023 site validation

**`chipexo_analysis.R`** — R analysis:
- DiffBind v3.20 + DESeq2 v1.50.2 differential binding
- 700 consensus peaks; 439 differential (WT vs spxA2KO, FDR < 0.05)
- Priority target annotation (Horstmann 2023 gene set)
- Composite, barplot, motif composition figures
- Supplemental tables ST1–ST5

### 3. Proteomics (`Proteomics/`)

**`proteomics_analysis_final.R`** — DIA proteomics:
- DIA-NN LFQ import and quality filtering (1,269 proteins)
- limma empirical Bayes: 5 comparisons (spxA1KO, spxA2KO, clpX_KO, pA2_A1, pA1_A2 vs WT)
- Three-tier functional annotation (Swiss-Prot curated → TrEMBL keyword → manual)
- Volcano plots, functional bar charts, FC heatmap, scatter figures

## Sample Naming Conventions

All scripts use the following standardized naming throughout:

| Abbreviation | Strain / Condition |
|-------------|-------------------|
| `WT` | Wild-type MGAS10870 (emm3) |
| `spxA1KO` | Isogenic Δ*spxA1* deletion mutant |
| `spxA2KO` | Isogenic Δ*spxA2* deletion mutant |
| `spxA2OE` | LiaSQ146A constitutively active LiaS mutant (SpxA2 overexpression surrogate) |
| `clpX_KO` | Isogenic Δ*clpX* deletion mutant (proteomics only) |
| `pA2_A1` | *spxA1* expressed from *spxA2* promoter (proteomics only) |
| `pA1_A2` | *spxA2* expressed from *spxA1* promoter (proteomics only) |
| `UI` | Uninduced (vehicle control) |
| `BAC` | Sub-MIC bacitracin |
| `hNP1` | Sub-MIC human neutrophil peptide-1 |

**Note on spxA2OE:** The LiaSQ146A (liaS-Q146A) isogenic mutant encodes a constitutively active LiaS sensor kinase that drives high SpxA2 expression independent of AMP induction. It is used as a SpxA2 overexpression surrogate in ChIP-exo experiments. NCBI BioSamples: SAMN60523488–490.

## Usage

### Running order

```
1. python3 NanoString_RNAseq/02_NS_genbank_crosswalk.py [args]
2. Rscript NanoString_RNAseq/01_NanoString_analysis.R
3. Rscript NanoString_RNAseq/02_RNAseq_DESeq2_validation.R
4. bash ChIPexo/chipexo_pipeline.sh
5. Rscript ChIPexo/chipexo_analysis.R
6. Rscript Proteomics/proteomics_analysis_final.R
```

### Path configuration

All scripts use `BASE_DIR` (default: current directory) as the repository root. Set before running if needed:

```r
# R
BASE_DIR <- "/path/to/SpxA1-SpxA2-MultiOmic-GAS"
```
```bash
# bash
export BASE_DIR="/path/to/SpxA1-SpxA2-MultiOmic-GAS"
bash ChIPexo/chipexo_pipeline.sh
```
